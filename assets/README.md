# Assets Directory

This directory contains static visual assets, styling resources, and optional documentation diagrams for **AI-PETase Optimizer**.

## Purpose

- Stores static SVG/PNG diagrams illustrating enzymatic depolymerization of poly(ethylene terephthalate).
- Stores structural snapshot previews for offline or low-bandwidth environments.
- All dynamic 3D molecular visualization is rendered client-side using WebGL via 3Dmol.js.
